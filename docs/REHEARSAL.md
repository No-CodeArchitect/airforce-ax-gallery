# 1회차(10/30 평택) 전 리허설 체크리스트

목표: 테스트 계정 3개로 **가입 → 작품 등록 → AI 분석 → 채점·댓글 → 순위 공개 → 발표 화면**을 한 바퀴 돌려 보고, 끝나면 흔적을 지웁니다.
소요 시간: 약 40분. 결과는 각 칸에 ✅/❌ 로 표시하고, ❌ 는 화면 캡처와 함께 Claude에게 알려 주세요.

주소: https://airforce-ax-gallery.vercel.app

## 준비물
- **관리자**: `jjh@airi.kr` (PC 브라우저)
- **테스트 교육생 3명 = 서로 다른 구글 계정 3개**: 교육생A·B·C
  - 개인 gmail 3개 정도면 됩니다. 한 브라우저에서 바꿔 가며 하려면 크롬 **프로필 3개** 또는 **시크릿 창 + 일반 창 + 휴대폰**으로 나눕니다.
  - 관리자 계정은 교육생으로 쓰지 않습니다 (실제 운영과 같게).
- **휴대폰 1대** (카카오톡 설치) — 인앱 브라우저·QR 확인용
- **썸네일용 이미지 3장** (아무 화면 캡처, 5MB 이하)
- **작품 배포 주소 3개**: 실제 바이브코딩 결과물이 없으면 누구나 열 수 있는 공개 페이지면 됩니다 (예: `https://example.com`). `localhost`·내부망 주소는 거부되는 게 정상입니다.

> ⚠ 리허설은 **실제 회차(SORTIE 01~05)가 아니라 별도 「리허설」 회차**에서 합니다. 실제 회차에 테스트 데이터가 섞이지 않게 하기 위해서입니다. 끝나면 마지막 단계에서 통째로 지웁니다.

> ℹ Anthropic API 키가 아직 없으면 AI 요약·심사평은 **「[목 심사평]」이 붙은 임시 결과**로 나옵니다. 이번 리허설에서는 정상입니다. 키를 넣은 뒤 「분석 실행」을 다시 하면 실제 심사평으로 바뀝니다.

## 6. 리허설 흔적 지우기 (꼭 하기)
리허설 데이터가 남으면 홈의 숫자 밴드·ACE 보드·회차 기록에 계속 보입니다.

1. **관리자**: 리허설 카드의 작품 3개를 각각 **삭제** (썸네일 파일도 함께 지워짐)
2. **Supabase** → SQL Editor → 아래를 실행 (리허설 회차의 채점·댓글·가입·회차를 지움)
   ```sql
   -- 작품 id 는 'pj_' + 가입 id 라서, 1번에서 작품을 지운 뒤에도 가입 정보로 채점·댓글을 찾을 수 있다
   with r as (select id from cohorts where slug = 'rehearsal')
   , p as (select 'pj_' || id as id from memberships where cohort_id in (select id from r))
   , d1 as (delete from scores   where project_id in (select id from p) returning 1)
   , d2 as (delete from comments where project_id in (select id from p) returning 1)
   , d3 as (delete from projects where cohort_id in (select id from r) returning 1)
   , d4 as (delete from memberships where cohort_id in (select id from r) returning 1)
   delete from cohorts where slug = 'rehearsal';

   -- 확인: 아래 다섯 숫자가 모두 0이면 깨끗합니다
   select
     (select count(*) from cohorts where slug = 'rehearsal') as cohort,
     (select count(*) from projects where cohort_id not in (select id from cohorts)) as orphan_projects,
     (select count(*) from memberships where cohort_id not in (select id from cohorts)) as orphan_members,
     (select count(*) from scores where project_id not in (select id from projects)) as orphan_scores,
     (select count(*) from comments where project_id not in (select id from projects)) as orphan_comments;
   ```
3. 홈 `/` 새로고침 → 숫자 밴드가 「첫 비행 준비 중 · 10/30 평택에서 이륙합니다」로 돌아왔는지 확인
4. 관리자 → `/sections` 에 SORTIE 01~05만 남았는지 확인
